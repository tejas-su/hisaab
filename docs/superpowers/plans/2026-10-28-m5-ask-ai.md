# M5 Ask AI Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Ask AI screen: pick a goal and period, preview the exact prompt, then copy it, share it, or open ChatGPT with it. The app itself sends nothing.

**Architecture:** New feature `lib/ask_ai/`. `GetPromptInput` loads the viewed cycle and the two cycles before it once. The pure `PromptBuilder` turns that input and the user's choices into deterministic text. Every toggle rebuilds the text synchronously in `AskAiBloc`, with no reload. Clipboard, share sheet and browser sit behind one `AiHandoff` port, so the bloc is tested with a fake. The Spends page gets the Ask AI card (FR-SP-2) that opens the screen for the cycle it shows.

**Tech Stack:** Flutter 3.47 / Dart ^3.13, flutter_bloc + bloc_concurrency, fpdart, get_it, intl, `share_plus` and `url_launcher` (new, both listed for M5 in PLAN §11).

**Spec:** [docs/SPEC.md](../../SPEC.md) BR-15, FR-AI-1 to FR-AI-4, FR-SP-2, NFR-2, NFR-3. Visuals: [UI_DESIGN.md](../../UI_DESIGN.md) §5.4 (card) and §5.5 (screen), plus mockup [07-ask-ai.html](../../design/mockups/07-ask-ai.html). The intended names come from [docs/features/ask-ai/01-architecture-overview.md](../../features/ask-ai/01-architecture-overview.md).

## Global Constraints

- Money is `Money` (int paise). Display goes through `MoneyFormatter` (`en_IN`). Never show paise. CSV amounts are `money.floorMajor`.
- "Today" comes from the injected `Clock`. Cycles come from `PeriodCalculator`, never from hand-rolled date maths.
- UI text lives in `lib/l10n/app_en.arb`, then run `flutter gen-l10n`. Banned words: "transaction", "debit/credit", "budget period", "Oops". The prompt body is an exception (Decision P1 below).
- Colours come from `HisaabColors`, type from the theme `TextTheme`, icons from `AppIcon` with a label, haptics from `Haptics`. No `Color(0xFF…)`, no `Colors.*`, no `Icons.*`.
- Marigold appears only on the selected-card check, the card well and the primary key. It is never placed bare on the light background.
- Blocs: sealed events named `AskAi…` in the past tense. Use `restartable()` for the load and `droppable()` for the hand-off actions. No Cubits.
- Hand-written fakes only. No `mocktail`, no `bloc_test`.
- Never log the prompt text, notes or amounts (NFR-3). `AppBlocObserver` already logs type names only, so keep it that way.
- Add no `INTERNET` permission. ChatGPT opens through an intent (NFR-2).
- Done means `flutter test` passes, `flutter analyze` is clean, and `scripts/changed_lines_coverage.sh` is ≥ 90% (target 100%).

## Decisions this plan makes

Each decision gets a DECISIONS.md row in Task 8.

- **P1:** The prompt body is fixed English text in `PromptBuilder`, not ARB strings.
  - It is addressed to the AI, not shown as UI copy, and it must stay byte-stable for the golden test.
  - Only category names are localised. They come in through a `nameOf` function.
- **P2:** Ask AI opens for the cycle that Spends shows, like *Every entry* (D53).
  - *This month* means that cycle. *Last 3 months* means that cycle plus the two before it.
- **P3:** The Ask AI card shows only when the shown cycle has spends.
  - On an empty cycle the AI has nothing to review, so the card would be a dead tap.
  - Because of this, there is no `AskAiEmpty` state. That is a departure from the feature doc.
- **P4:** The toast "Copied. Paste it in the chat." shows in two cases: *Copy only*, and *Copy & open ChatGPT* when the link cannot carry the text (it is too long, or no app opened it).
  - A short prompt that prefills ChatGPT shows no toast. *Other AI* shows no toast either, because the share sheet is the feedback.
- **P5:** One `AiHandoff` port replaces the doc's three services (Clipboard, Share, Launcher).
  - There is one fake, and the bloc has one dependency.
- **P6:** The grouping weeks are 7-day blocks counted from the period start, not calendar weeks.
  - Grouping folds the oldest blocks one at a time until the text is ≤ 12,000 `String.length` units.

## Review Focus

These cases are not obvious from the SPEC. Each one gets a test in the task named.

1. **A note containing a comma, a double quote or a line break** must stay one CSV field. Escape it the RFC 4180 way. A renamed category name gets the same escaping. (Task 2)
2. **A text of exactly 12,000 characters is not grouped. 12,001 characters is grouped.** The same input always gives byte-identical output. (Task 3)
3. **An encoded prompt of exactly 2,000 characters prefills the ChatGPT link. 2,001 characters falls back** to `https://chatgpt.com/` plus the toast. (Task 1)
4. **The launcher returns false** (no browser, no ChatGPT app). The text is already copied, so the toast still shows and nothing throws. (Task 6)
5. **"Ask my own question" with a blank or whitespace-only question.** All three actions are disabled, and the trimmed question goes into the prompt. (Tasks 6 and 7)

### Task 2: `PromptBuilder`: sections, CSV and goals

**Files:**
- Create: `lib/ask_ai/domain/prompt_builder.dart`, `lib/ask_ai/domain/prompt_csv.dart`
- Test: `test/ask_ai/domain/prompt_builder_test.dart`, `test/ask_ai/domain/prompt_csv_test.dart`
- Fixture: add `static PromptInput promptInput` to `test/helpers/fixtures/ledger/worked_example.dart`, if that file may import `ask_ai`. Otherwise put it in a new `test/helpers/fixtures/ask_ai/prompt_input.dart` (preferred, so the ledger fixture stays ledger-only).

**Interfaces:**
- Consumes: the Task 1 types; `MoneyFormatter`; `PayRule` subtypes.
- Produces:
  - `abstract final class PromptBuilder { static const int maxLength = 12000; static PromptText build(PromptInput input, PromptChoice choice, {required String Function(Category) nameOf}); }`
  - `abstract final class PromptCsv { static String field(String value); }`

**The template:** text is joined with `\n`, with no trailing newline. Each line below is a contract.

| Line | Content |
|---|---|
| 1 | `You are a friendly money coach. Be specific, use my numbers, no jargon.` |
| 2 | `Context: income {income}, currency {code}, period {start}..{end}, today {today}.` |
| 3 | `Spent {spent}, got {got}. By category: {rows}.` |
| 4 | `Recurring bills: {bills}.` |
| 5 | blank |
| 6 | `Entries (CSV):`. When weeks are grouped, Task 3 inserts its line just above this one. |
| 7 | `date,amount,kind,category,note`, or `date,amount,kind,category` when `hideNotes` is on |
| 8… | one row per entry, oldest first, ordered by `(date, id)` |
| then | blank, then the task line |

How each placeholder is filled:
- **`{income}`:**
  - When the income rule is present: `MoneyFormatter.format(rule.amount)` + `/month`, or `/week` when the rule's frequency is weekly, then ` ({payday})`.
  - When there is no income rule: `varies`.
- **`{payday}`** depends on the `PayRule`:
  - `MonthlyOnDay(d)`: `payday {ordinal(d)}`, giving 1st, 2nd, 3rd, 4th, 11th, 12th, 13th, 21st, 22nd, 23rd, 31st.
  - `LastDayOfMonth`: `payday last day of the month`.
  - `WeeklyOn(w)`: `paid every {Monday…Sunday}`.
  - `IrregularIncome`: `no fixed payday`.
- **Period:** the first `period.cycleCount` items of `input.cycles`. `{start}` is the oldest one's start and `{end}` is the newest one's end, both as `toIso()`. Only entries inside the period and on or before `today` are used.
- **`{spent}`, `{got}`:** `MoneyFormatter.format` of the period's totals.
- **`{rows}`:** spent categories with spend > 0, biggest first, ties broken by `sort`.
  - Each row is `{name} {digits}`. Add ` (limit {digits} a month)` when the category has a limit.
  - Rows are joined with `; `. When there are no rows, write `none`.
- **`{bills}`:** `input.bills` sorted by `nextDue`, then by `id`.
  - Each bill is `{label} {digits} monthly on day {schedule.anchor.day}`. For a frequency other than monthly, write `{label} {digits} {frequency.name}`.
  - Bills are joined with `; `. When there are no bills, write `none`.
- **CSV row:** `{date.toIso()},{amount.floorMajor},{kind.name},{PromptCsv.field(nameOf(category))}`.
  - When notes are shown, add `,{PromptCsv.field(note ?? '')}`.
- **Task line**, for each goal:
  - `reviewMonth`: `Task: Review my month. Give: 1) the 3 biggest problems 2) 3 concrete savings with ₹ amounts 3) a budget per category for next month 4) one habit to change.`
  - `helpMeSave`: `Task: Help me save more. Give 5 specific cuts with ₹ amounts a month, easiest first, and the total I would save.`
  - `makeBudget`: `Task: Make me a monthly budget per category that fits my income and leaves room to save. Show a table with ₹ amounts and one line on why for each.`
  - `onTrack`: `Task: Am I on track to last until my next payday? Compare my spending pace with the days left and tell me how much I can spend each day from now.`
  - `ownQuestion`: `Task: {question.trim()}`
- **`entryCount`:** the number of entries in the period. **`groupedWeeks`:** 0 (Task 3 changes this).

### Task 3: `PromptBuilder` size guard

**Files:**
- Modify: `lib/ask_ai/domain/prompt_builder.dart`
- Test: `test/ask_ai/domain/prompt_builder_size_test.dart`

**Interfaces:**
- Produces: `PromptText.groupedWeeks` > 0 when grouping happened. The signature of `build` does not change.

**The algorithm:**
1. Split the period into 7-day blocks from its start date. The last block may be shorter.
2. For k = 0, 1, … up to the number of blocks, build the text with the k oldest blocks grouped.
3. Return the first k whose `text.length <= maxLength`. If none fits, return the result with every block grouped.

**Grouped output:**
- Grouped entries leave the CSV.
- Insert this line just above `Entries (CSV):`: `Earlier weeks (spent/got): {start}..{end} {spentDigits}/{gotDigits}; …`, oldest first.
- A block with no entries is still listed, as `0/0`, so the dates stay continuous.
- `entryCount` still counts every entry in the period.

- [ ] **Step 1: Write the failing tests**

### Task 4: `GetPromptInput` use case and DI

**Files:**

**Interfaces:**
- Consumes: `LedgerRepository`, `RecurringRepository`, `BudgetSettingsRepository`, `CategoryRepository`, `PeriodCalculator`, `Clock` (all through `ledger.dart` and `core`).
- Produces: `final class GetPromptInput implements UseCase<PromptInput, PayCycle>`.
  - Its constructor takes `required this._ledger, required this._recurring, required this._settings, required this._categories, required this._periods, required this._clock`, in the same style as `GetSpendsOverview`.
  - `void registerAskAiServices(GetIt getIt)` registers `GetPromptInput` and `AiHandoff` (Task 5 adds the handoff line).

**What `call(cycle)` does:**
1. Read the settings and the active rules.
2. Work out the pay rule with `PayRuleSchedule.payRuleOf(<income rule>)`.
3. Build the cycles `[cycle, before(cycle), before(before(cycle))]`. `before(c)` is `periods.cycleFor(today: c.start.addDays(-1), rule:, monthStart:)`, the same steps `GetSpendsOverview._cyclesBack` uses.
4. Load `entriesBetween(cycles.last.start, minOf(cycle.end, today))` and the categories.
5. Set `incomeRule` to the rule with `isIncomeSource`. Set `bills` to the active rules with `kind == EntryKind.spent`.

The failures are the repositories' `Left`s, passed through unchanged.

- Produces:
  - **Constructor:** `AskAiBloc({required PayCycle cycle, required this._getInput, required this._handoff, required this._haptics, required String Function(Category) nameOf})`.
  - **Events** (all `sealed AskAiEvent`):
    - `AskAiLoadRequested`: uses `restartable()`.
    - `AskAiGoalChosen(AskGoal goal)`, `AskAiPeriodChosen(AskPeriod period)`, `AskAiNotesHidden(bool hide)`, `AskAiQuestionChanged(String question)`: sequential, the default.
    - `sealed AskAiHandoffEvent`: `AskAiChatGptPressed`, `AskAiOtherAiPressed`, `AskAiCopyPressed`. Uses `droppable()`.
  - **States** (all `sealed AskAiState`):
    - `AskAiLoading`
    - `AskAiFailed`
    - `AskAiReady({required PromptInput input, required PromptChoice choice, required PromptText prompt, int toasts = 0})`

**Behaviour:**
- **Load:** the bloc emits `AskAiReady` with a `PromptBuilder` result for the default `PromptChoice`. A `Left` emits `AskAiFailed`.
- **Choices:** every choice event replaces `choice` and rebuilds `prompt` synchronously. Goal, period and notes changes call `haptics.tick()`. A question is cut to `PromptChoice.maxQuestionLength`.
- **Hand-off events** are ignored unless the state is `Ready` and `choice.canSend` is true.
  - **ChatGPT:**
    1. `copy(text)`.
    2. Open `ChatGptLink.prefilled(text)`, or `ChatGptLink.home` when that is `None`.
    3. Then `toasts + 1` when the link was `home` or `open` returned false (Decision P4).
  - **Other AI:** `share(text)`. No toast.
  - **Copy:** `copy(text)`, then `toasts + 1`.
  - Each hand-off calls `haptics.success()` once it completes.
