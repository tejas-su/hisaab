Today, without the blocks proposal

The owner rejected mockup 22's fixed blocks: blocks just don't do the job. The This week bars do. They have a real height, a tick for "your share" and a stripe for "over", and they can be read like any chart. So these four directions drop the block row. T1 uses the week bars' own language for Today mode. T2–T4 are different shapes, shown for contrast. All four keep the hero amount, the payday flag, the range line and the rule of one signal colour.

Recommendation T1

One week chart for both modes. The owner already likes it, so the hero can use one chart instead of two. Every bar means the same thing everywhere. Grey height = spent, the tick = that day's share, and stripes = over. Today adds one thing: marigold room from what's spent up to the tick, which is exactly the hero amount. Days still to come are outlines at the share they'll get, so overspending today visibly lowers them (BR-6's shrinking later blocks, in bar form). Tapping still switches to the week sentence, but the chart stays put: no swap, no crossfade, no resize. The cost is height. The card is 88dp of bars all the time, so the Today list starts 48dp lower. That's the W3 option D111 turned down; it is worth taking again now that the blocks are going.
