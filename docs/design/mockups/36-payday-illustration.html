Onboarding illustrations: three sets

The Charco Plus grammar carried across the three onboarding questions. Every picture has three scribbled rocks in charcoal, taupe and marigold, one ink object with stipple shading, and sparkles. There are no faces. Within a set, the idea stays the same from screen to screen, so the three steps read as one story. Each set is shown on the real screens, in the order the user meets them.

Recommendation

Set A, Hands up. It grows straight out of the calendar-in-hand you approved. The same hand appears on every step, so onboarding feels like one person helping. Each object also answers its question on its own: the calendar says when, the pencil ringing a day says which day, and the bill says bills. Set B, Planted is the runner-up. It is calmer, and the genda phool tie marigold to something Indian. Set C, Floating is the most playful, but the bunting is busy at phone size.

Build notes

ConcernPlan
AssetFinal art is drawn in Figma and exported as WebP at 3×, one file for light and one for dark per picture (6 files for a set), shown with Image.asset. That needs no new package.
ColourSix illustration-only tones (dark, mid and light rock, plus their scribble tints) become named tokens. Ink and paper come from ink and surface.
FitThe picture fills the gap between the hint and the controls with BoxFit.contain, so it shrinks on the day grid (the tallest controls) and grows on the bills step. It is dropped when the gap is under about 120dp, for example on a landscape phone, so controls never scroll.
SemanticsDecorative: ExcludeSemantics.
LaterThe same set can cover Which day of the week? and step 1, How much money comes in each month?, if you want those too.
DocsA pick needs a DECISIONS row and an illustration section in UI_DESIGN (style, tones, which screens get a picture).
