When does it come? Illustrations

Static pictures for the empty gap on onboarding step 2, in the style of Charco (ink objects with stippled shading, sitting on chunky patterned rocks) and Grads v2 (grainy gradients), with smiling faces. These are original drawings, not copies of either pack. Charco is multicolour, so the rocks here use hisaab's warm greys and one marigold, keeping the app's no-red, no-green rule. There is no motion.

Expressions

The same face kit fits every character (calendar, coin, envelope). One expression is picked per picture; Smile is the default. If you want, the other steps can reuse the kit later. For example, It changes could get Hmm, and the done screen could get Big grin.

Recommendation

1, Happy calendar on rocks. It is the closest to Charco, and the calendar answers the question ("when?") without words. The smile and the wave make the step feel friendly rather than like a form. 4, Payday friends is the runner-up if you want the coin in it too, but it is busier at phone size. 3 is the Grads option. It is the warmest, but a large marigold glow stretches the "marigold means today" rule.

FormatOne static vector per picture. Shipping it as an SVG file needs flutter_svg, which is not in PLAN §11 (I'll ask before adding it). Without it, hand-port the picture to a CustomPainter. Either way, colours come from context.colors, so dark theme works without a second file.
TextureStipple and grain are drawn as a fixed dot pattern baked into the vector, not as a live noise filter, so it renders the same on every phone and stays cheap on low-end ones.
