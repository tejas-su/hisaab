Today: the Add tray, prefilled current

Editing replays Add. To change only the note you still pass the keypad, tap Next, and tap the category again, and the grid doesn't show which one it was.

V1 · Patched tray smallest change

Same two steps, three fixes: the first digit replaces the amount, the grid marks the current category, and Delete moves up to step 1. It fixes the worst surprise (₹2,503) but still makes you re-confirm the category.

V2 · Entry card with Change rows matches the bill sheet (D118)

Tapping an entry opens a card showing all of it. Each row opens just that one question, and that question saves on its own: the keypad's key reads Save, a tile tap saves, a day tap saves. The sheet closes and a snackbar offers Undo. Nothing is half-edited, so there is never a "discard?" prompt.

V3 · One edit form like most money apps

Everything on one sheet, with one Save at the bottom: the amount (tap for the keypad), a compact category grid with the current one marked, the day, and the note. This is the Wallet and YNAB pattern. It needs a "leave without saving?" prompt (Material), and the grid is smaller than in Add.

V4 · Tray opens on the category step recommended

Same tray and widgets as Add, but editing opens on step 2: the amount in the title (tap it for the keypad), the current tile marked, the day and note already showing, Delete, and a marigold Save. A tile tap saves, just as in Add, so moving to another category is 2 taps. A note or day change ends with Save, so the category is never re-picked.

Applies to whichever version is picked

  • The first digit replaces a prefilled amount, and ⌫ first edits it. This removes the ₹2,503 trap. Quick-add chips (+₹50) still add to the amount on screen.
  • Mark the current category with an outline and a tick, plus "Food, now" in TalkBack. No colour is used.
  • Undo after an edit, for 4 s (held with TalkBack), naming what changed: "Moved to Travel", "Changed to ₹350", "Note changed". This changes BR-10, where a save from the tray has no Undo.
  • Delete one tap from the start in edit mode, not hidden behind Next.
  • Unchanged: Add's path (Add → digits → Next → tile), fixes and Used entries (still not editable), and the your usual pill (never shown in edit).
