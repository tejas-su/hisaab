Recommendation B1 · Bites

Each spend takes a bite. It is still just a bar, so a five-year-old reads it as "yellow is what I can still spend". But it isn't plain, because it shows the user's own day. Chai is a nibble, groceries are a big chunk, and the newest bite slides in next to the yellow as the number rolls down. That is the moment the bar comes alive, and it ties the Add flow to the hero without adding a word. Over today reuses the week bars' language (tick = share, stripes = over), so This week still feels related. Days rail: leave it off by default. The range line already says "Lasts till payday", and the rail is the first thing to cut if the hero feels busy again.
