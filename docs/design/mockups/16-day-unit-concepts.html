Day unit concepts Proposal, not agreed in SPEC

Follows mockup 15, which was rejected for its capsules and its double-wide today. Every day here has the same width again. Marigold sits only on today's unit, with the 1.5dp displayEdge ink edge in light. Future days are grey. There is no red or green; state is fill, hatch, outline and words. The tokens, etched hero, springs (critically damped, sampled into CSS linear()), Reduce motion toggle, pressable card and worked example are mockup 15's, and so are its accessibility fixes: max fill 0.86 once anything is spent, 2dp hatch 6dp apart, displayInk2 outlines for over-for-cycle and ghosts, "rupees" spoken, and a flag column that sizes to its date. Each concept gets one showpiece. All three share a new weighted landing (a 3% squash on the new land spring) and digits bound to the fill spring, so the number stops on the same frame as the level.

Counting at 28 days 8.4dp stubs, no gaps. Seams are dashed perforations in display, plus 1.5dp notches at the top and bottom (1.53:1 against blockIdle, the same step as any day block's edge). Monday dates, turned upright, mark the weeks, so you count in weeks, not stubs. The faintest separation of the three. 6.1dp ingots with 2dp gaps. The facets merge into a flat face with one highlight line, so each one reads as a bar with a slight taper. As countable as 15's pills. 6.1dp notes with 2dp gaps. The keyline (below 8dp) and the roundel (below 12dp) are gone, so at 28 days it is plain rounded bars: the concept disappears.
Wow moment Morning tear, about 2.2s, once a day, any tap skips it. Yesterday rips off with a lightImpact, curls and falls. Rare, so it can stay special. The glint wave on a morning after an underspend: the ingots swell in a domino stagger and a sheen rakes across each bevel. Only on a good morning, so it reads as a reward. The scrap: on every spend, the spent slice tears off and flies up out of the card. Strong once, but it plays on every spend, so it may wear thin by week two.
Paint cost Per stub: one path with four arcs, a fill, a dashed seam line and an optional date (cached TextPainter). The tear adds one transformed layer for 450ms. Cheap. Per ingot at ≤20 days: an outer polygon, four facet polygons, three brush lines and a minted ₹. The glint adds one clipped polygon for each ingot for about 600ms. The heaviest static paint, still fine for a CustomPainter. Per note: a rounded rect, two keylines, a roundel and a deckled edge (about w / 1.6 points). The scrap needs a layer above the card (an Overlay entry), because the card clips. Cheap paint, extra plumbing.
